# KIBOU Worlds 開発ガイド

## このプロジェクトについて

架空の島で、資源と協力のルールを比較する研究用プロトタイプです。
現在のエージェントは明示的なルールで動き、LLMを呼び出しません。
実験結果を実在する人や社会についての結論として扱わないでください。

## 準備

Node.js 22以上とGitを用意し、この公開リポジトリを自分のアカウントへForkします。
Forkしたコードを取得し、プロジェクト内で実行します。

```sh
npm ci --ignore-scripts
npm run dev
```

表示されたローカルURLをブラウザで開きます。サーバーは自分の端末内だけに
公開されます。APIキー、データベース、会員アカウントは必要ありません。
右上で英語と日本語を切り替えられます。

## 10分でできる最初の変更

1. 作業ブランチを作成します。
2. `src/WorldsLab.tsx` 内の英語・日本語ラベルを一箇所改善します。
3. 同じシードで実験を開始し、停止・1ステップ・分岐を確認します。
4. `npm run check` を実行します。
5. 変更理由と実施した確認を記載してPRを送ります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/simulation.ts` | 乱数、状態遷移、資源、日次集計 |
| `src/WorldsLab.tsx` | 実験操作、分岐比較、ローカル書き出し |
| `src/WorldCanvas.tsx` | 架空の島の描画。外部画像は使いません |
| `src/LocaleProvider.tsx` | タブ内だけの言語設定 |
| `tests/` | 再現性、操作、画布が使えない場合のテスト |
| `public-export.json` | 公開してよいファイルの一覧 |
| `scripts/` | 公開範囲とGit作者メールの確認 |

## 実験を追加するとき

問い、仮説、シード、ルール、測定方法、限界を先に記載します。
元の状態を変更しない純粋な状態遷移を保ち、同一シードの再現テストを追加します。
エンジンの意味が変わる場合、バージョンと実験プロトコルも更新します。
詳細は `docs/EXPERIMENTS.md` を参照してください。

## 確認

```sh
npm run check
npm audit --ignore-scripts --audit-level=moderate
```

スマートフォン縦画面、キーボード、停止、リセット、分岐、書き出し失敗、
未書き出しでの移動も確認します。未実施の確認はPRに正直に記載します。

## 安全な共同開発

Issue、PR、画像、コミットの履歴はすべて公開されます。
実名、個人メール、学校名、住所、個人のネットワーク情報、認証情報、
本番サービスのデータや設定を提出しないでください。
Git作者には公開ユーザー名とGitHubのnoreplyメールを使用します。
新しいファイル、依存パッケージ、素材は一覧を更新してレビューを受けます。
他人のコードや素材を使う前にライセンスを確認してください。

外部PRのCIに本番Secretは渡しません。提出コードは自動で本番へ入りません。
運営によるレビュー後に取り込みます。コードMIT、独自の架空の視覚素材CC BY 4.0、
ブランドの権利は留保します。実サービスの会員機能とは完全に分離されています。

## データの扱い

実験は現在のタブのメモリ内だけに保持され、更新すると失われます。
JSONは利用者の操作で端末にダウンロードします。自動アップロードはありません。
ただし公開サイトの配信元や、リンク先へ移動した際のGitHubは通信元の情報を
取得できます。このアプリを匿名化サービスとして扱わないでください。
